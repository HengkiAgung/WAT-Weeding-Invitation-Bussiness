# Workflow: Analyze Invitation Template

## Objective
Turn an invitation template (own or reference) into structured knowledge so new templates can be generated and existing ones converted into Template Packages.

## Inputs
- `template_dir` — folder with `index.html`, css, js, assets (e.g. `wedding-template/`)
- `template_id` — short slug (e.g. `eloise`)

## Tools
- `graphify` skill (`/graphify <path>`) — builds knowledge graph → `graphify-out/` (project root)
- `graphify update <path>` — re-extract code only, no LLM
- `graphify explain "X"` / `graphify path "A" "B"` — query the graph
- `graphify add <url>` — add external demo page to corpus (`raw/`)

## Steps
1. Read `index.html`, config/data file, main JS, CSS (tokens + section comments), assets list, README.
2. Fill a `knowledge/template-<id>.md` (or `template-anatomy.md` for the reference) with the same sections as `knowledge/template-anatomy.md`:
   file map · rendering model · section inventory (id, purpose, data paths, libs, required?) · data model · theming tokens + hardcoded colors · hardcoded strings · libraries & licences · layout/motion · behaviour gaps · clone checklist.
3. Quick greps that must always be run:
   - hardcoded colors: `grep -c "#[0-9a-fA-F]\{3,6\}\b\|rgba\?(" css/*.css`
   - token usage: `grep -o "var(--[a-z0-9-]*)" css/*.css | sort | uniq -c`
   - CDN libs: `<script src=` / `<link href=` in `index.html`
   - bindings: `grep -o 'data-t="[^"]*"' index.html`
4. Flag licensing (GPL libs, commercial fonts, stock photos) in PROGRESS.md decision log.
5. Rebuild graph from project root: `/graphify . --update` (new/changed docs, uses LLM) or `graphify update .` (code only, free).

## Outputs
- `knowledge/*.md` analysis docs
- `graphify-out/` graph (graph.json, GRAPH_REPORT.md, graph.html)

## Edge Cases & Learnings
- `wedding-template/` is a nested git repo — never move it; copy into `templates/<id>/` when refactoring.
- Placeholder SVGs are generated by `wedding-template/tools/build-assets.js` with hardcoded colors.
- graphify is pip package `graphifyy` (double y), CLI `graphify`; skill installed via `graphify install --platform claude`.
- Run graphify from project root, not `knowledge/` — the query fast-path looks for `graphify-out/graph.json` in cwd.
- `.graphifyignore` excludes `wedding-template/assets/` (39 placeholder images = 39 vision agents, low value).
- Windows: set `PYTHONIOENCODING=utf-8` when printing GRAPH_REPORT.md (cp1252 chokes on arrows).
- `.css` files are unclassified by graphify detect — CSS knowledge must be captured in the anatomy markdown.
