# Kompetitor & Harga — Undangan Digital Indonesia (riset 2026-09-24, S2)

Sumber: halaman harga resmi, dicek lewat WebFetch/WebSearch. Beberapa situs (Satu Momen) menolak fetch (HTTP 402), jadi datanya dari snippet pencarian. Anggap angka ini sebagai snapshot, bukan data pasti.

## Ringkasan pasar
- Harga pasar terbagi 4 lapis:
  - **DIY murah Rp0–150rb**: sebagian besar self-serve.
  - **Vendor menengah Rp200–750rb**.
  - **Premium/custom Rp500rb–3jt**.
  - **Layanan hari-H Rp1–2jt+**: buku tamu, usher, dan RSVP assistance.
- Fitur inti sudah jadi **komoditas**. Hampir semua paket berbayar punya nama tamu unlimited, RSVP, peta, countdown, musik, galeri, dan amplop digital. Pembeda antar-vendor ada di **desain/tema**, **kuota galeri**, **masa aktif**, **revisi**, **custom domain**, **WA blast**, dan **buku tamu QR**.
- Model bayar dominan: **sekali bayar per undangan**. Langganan ada (Indoinvite) tapi ditujukan ke reseller/WO.
- Diskon coret harga ("Rp350rb → Rp49rb") sangat umum dipakai.
- Marketplace (Tokopedia/Shopee) diisi penjual kecil: proses 1×24 jam, masa aktif 1 tahun, dijual per paket BASIC/PREMIUM/PLATINUM, dan pelanggan kirim data lewat chat. Pengerjaannya manual, jadi di sini ada **peluang otomatisasi**.

## Implikasi untuk produk kita
1. **Posisi harga yang disarankan: DIY-plus, Rp79rb–249rb.** Di bawah Rp50rb pasar sudah jenuh (perang harga). Di atas Rp400rb pembeli mengharapkan layanan manusia. Draft tier:
   - **Hemat ±Rp79rb**: 1 template, galeri 10, aktif 6 bln, link tamu unlimited, RSVP, ucapan, amplop digital.
   - **Lengkap ±Rp149rb**: galeri 20, video, live streaming, love story, import Excel tamu + teks WA, aktif 1 thn.
   - **Premium ±Rp249rb**: template premium/motion, QR check-in + layar sapa, dashboard RSVP per acara, aktif lifetime (atau 2 thn).
   - **Add-on**: custom domain, perpanjangan, bahasa kedua, dan (nanti) WA blast via API berbayar.

   Harga final diputuskan user nanti, di S8.
2. **Quick buy** jadi pembeda utama. Pesaing marketplace masih manual lewat chat; kita bisa jadi "bayar → langsung jadi".
3. **Import Excel → link per tamu + teks WA** baru ada di vendor mahal (Invitato, Viding) atau aplikasi buku tamu terpisah (Hadirly, BukuTamu Pro). Memasukkannya ke tier menengah adalah **nilai jual kuat**.
4. **Trial/preview gratis** (Satu Momen 12 jam, Menica 1 hari) sudah jadi standar → demo ber-watermark wajib ada (sesuai rencana S10).
5. Masa aktif termasuk pertimbangan pembeli. "Lifetime" dipakai sebagai daya tarik, tapi ada biaya storage → gunakan batas waktu + perpanjangan murah, lalu arsip otomatis (aset dipindah ke storage dingin).
6. Tema adat/regional sangat dicari (Acaranya punya 23 tema Jawa) → volume template > kecanggihan editor. Ini memvalidasi model Hybrid + spesifikasi clone template (S3–S4).
